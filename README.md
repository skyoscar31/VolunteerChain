# VolunteerChain

A decentralized community volunteer service tracking and reward system for incentivizing civic engagement on Stacks blockchain.

## Features

- Volunteer service tracking with hour-based rewards
- Community volunteer level progression with bonus multipliers
- Volunteer point accumulation and redemption
- Community project optimization with time-based penalties
- Comprehensive volunteer program statistics

## Smart Contract Functions

### Public Functions
- `start-volunteer-service` - Begin community volunteer service
- `complete-volunteer-service` - Complete service and earn rewards
- `claim-volunteer-rewards` - Claim accumulated volunteer points
- `optimize-community-projects` - Optimize projects with point investment
- `complete-project-optimization` - Complete optimization process

### Read-Only Functions
- `get-service-count` - Get user's total volunteer services
- `get-volunteer-point-balance` - Get user's volunteer point balance
- `get-volunteer-level` - Get user's volunteer level
- `get-volunteer-program-stats` - Get overall program statistics

## Reward System
- Base reward: 20 points per service
- Community bonus: 7 points per level (max level 10)
- Optimization multiplier: 3x for community projects

## Usage

Deploy the contract to create a volunteer incentive system where community members can track service hours, earn rewards, and optimize community projects.
